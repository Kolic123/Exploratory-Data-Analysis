# Exploratory Data Analysis & Regression Modeling

## What's Inside

- `LINE & lin reg.ipynb` — Data filtration, LINE assumptions testing and linear regression  
- `time_series.ipynb` — Visual analysis, STL decomposition, Autocoreelation and Partial Autocoreelation analysis and training of ARMA model on time series    

## Tools

Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn

## Note

The original datasets are no longer available. The notebooks include all code, textual analysis and outputs
(plots, metrics, model results) from the original analysis. The workflow and methodology
are fully reproducible with a similar dataset.
